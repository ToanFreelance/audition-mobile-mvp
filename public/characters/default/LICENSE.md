# Legacy P3.1 RobotExpressive validation asset

`character.glb` is the **RobotExpressive** test model distributed with the official Three.js examples. It was the active Phase 3 validation asset through P3.6 and is retained in the repository as a legacy/debug reference after P3.7 switched the active character to the pinned Quaternius human pipeline.
