# P3.7 — Human Character Asset Swap + Dance Validation

Status: **implementation complete — awaiting owner iPhone visual QA**.

P3.7 replaces RobotExpressive as the active validation character with a pinned Quaternius human humanoid and eight curated CMU dance motions. The completed P3.1–P3.6 architecture remains unchanged in authority: WebAudio/song time owns beat-critical phase, each successful move anchors to the player's factual SPACE timestamp, choreography selection is deterministic, and the 150 ms cross-fade remains presentation-only.

## Active human presentation set

- Idle: neutral Quaternius reference pose.
- Normal success pool: eight real mocap-derived moves (`dance-01` through `dance-08`).
- Miss/Bad: curated crying/fail motion, then neutral Idle.
- Successful Finish: one-shot jump/kick/spin special, then neutral Idle; its duration does not affect the scheduler.

The motion source IDs and licensing/provenance are documented in `public/characters/human/README.md`.

## Implementation notes

- Human GLB is pinned to an exact public CC0 source commit and loaded through jsDelivr for this validation milestone.
- CMU BVH sources are pinned to an exact mirror commit.
- A fixed Quaternius-to-CMU bone map is applied once during `CharacterActor.load()` using Three.js `BVHLoader` + `SkeletonUtils.retargetClip`.
- Retarget output is sampled at 30 fps and only curated windows are retained in memory.
- Generated pelvis translation tracks are removed to keep the actor stage-centered; body/bone rotations remain intact.
- The old local RobotExpressive GLB remains in the repository only as a legacy/debug reference.
- If the pinned external human/mocap load fails, the existing procedural fallback keeps gameplay running.

## Locked regressions that P3.7 must not change

- Mobile DPR/lighting/visibility optimizations from P3.6.
- P3.5 camera/framing values and normalized height 3.4.
- P3.4 150 ms song-time-derived cross-fades and same-clip action lanes.
- P3.3 exact per-player SPACE timestamp anchors.
- Successful Finish `38 → 39–42 hidden → 43 L6 visible` and cadence `38,62,86,110`.
- Missed Finish two-hidden-turn behavior.
- L6+ suppressed command reveal at Perfect center.
- AUDIO END as the only game-end condition.

No Phase 4 multiplayer work is included.
