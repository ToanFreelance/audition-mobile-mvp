## Finish / multiplayer-ready scheduler contract

Finish is one shared global turn. Player judgement is not allowed to own the clock or the room command schedule.

For the deterministic Aloha QA cadence, a non-final Finish such as T38 always schedules:

- T38 Finish;
- T39–T42 shared hidden/rest global turns;
- T43 shared L6 visible command.

This schedule is identical whether an individual player gets Perfect, Great, Cool, Bad, or Miss. Miss consequences remain player-specific presentation/scoring state only. AUDIO END remains the only game-end condition.
