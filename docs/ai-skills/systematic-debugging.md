# Trace the root cause
Use when a real test, build, deploy or runtime error occurs. Capture exact SHA, failure message, triggering input, timing, observed/expected output. Distinguish setup/transport failure from product behavior. Trace actual call chain and state transitions; compare baseline, isolate smallest repro; state source inference vs observed runtime. Form one falsifiable hypothesis, test it without changing protected clock/security/gauge. Use focused regression RED before production fix, then GREEN. Max two repair attempts for same cause; preserve evidence and escalate if unresolved. Never fix symptoms with offsets, extra turns, arbitrary retries, weakened gates, silent fallback, or unrelated refactor. Context7 only for public library API uncertainty; compare installed version before using.
