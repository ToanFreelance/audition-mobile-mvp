## Rig and swap behavior
1. Load both GLBs with Three.js GLTFLoader.
2. Basic scene is the single actor. Basic has 17-bone skeleton and its original face/hair.
3. Premium wearable SkinnedMeshes reuse the original Basic skeleton bones and a copied inverse-bind matrix from Premium's same-name/order rig.
4. Basic/Premium selection changes only mesh visibility. Actor, bones, and `AnimationMixer` do **not** get rebuilt and dance time does **not** reset when selecting an outfit.
5. Dance loop is a local animation preview at roughly 120 BPM, not the game WebAudio authoritative clock.
6. Stop resets original bone positions/quaternions; Play restarts the demo clip.

## Risks / remaining work
- The procedural avatar is simpler than the accepted fashion concept; materials, hair, head and garments need proper artistic sculpt/texture authoring.
- Skinned geometry can still clip during extreme movement. This demo checks basics, not production animation quality or full choreography.
- Adding Python build-only dependencies increases the preview build time and requires Python3+pip on Vercel build; verify final Preview build and deployment logs.
- No shop, purchases, VIP entitlement, saved wardrobe data, or gameplay integration in this scope.
